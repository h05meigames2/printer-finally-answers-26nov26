## The entry

**120 characters** — one line, within the 1–240 character limit.

## Why this line

- **The printer's own voice:** tired, literal, slightly passive-aggressive — a machine that counts every sheet and keeps score.
- **Instantly funny:** the joke lands in a single read, no setup.
- **Fresh angle:** not a recycled "have you tried turning it off and on again" gag — the printer blames the user with arithmetic (46 of 48 printed flawlessly = 97.9% not its fault).
